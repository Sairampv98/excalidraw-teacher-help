A real click-through installer for the offline setup: a wizard with the choice of what to install, a launcher with no console window and a tray icon, a desktop and Start menu shortcut, an uninstaller, and the developer tools (Python, Java, Node, C and C++, VS Code) installed for the user alone with no admin rights.
