Wave 4b - reformat a selection as a code card or as a table. Two of the owners nine observations. Observation 3: in PDF files, if I copy code parts only and paste it into the canvas, then I should be given the option to reformat it after selecting the entire group of text boxes into the same format as when I paste markdown code that was copied and pasted using keyboard shortcut. Observation 4: in Markdown files, whenever there is a table and it is copied into the canvas it does not turn into a table automatically - only turns into text boxes right now. I want it to be selectable and an option to turn it into a smart table with all the text boxes filled in and tables drawn automatically and appropriately. The owners decision: the two are ONE action over a selection, offering both formats - not two separate actions. The library cannot do the work itself (the code card is the apps - it needs shiki, an app dependency), so the library gains a new onReformatSelection prop and the canvas context menu gains a Reformat as... entry that calls it; the app owns the chooser and the two reformats. The code-card reformat reuses the apps existing insertCodeIntoScene and deletes the original text elements; the table reformat recovers the cells from each line (markdown pipes, or tabs for a spreadsheet or PDF copy), drops the markdown separator row, lays the cells out on a grid and DRAWS it as a rectangle per cell behind ordinary selectable text elements. The design is docs/superpowers/specs/2026-10-21-reformat-selection-design.md and the build sheet is docs/tins-tasks/wave4b-reformat-selection-brief.md - read both before writing code.
