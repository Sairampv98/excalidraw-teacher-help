Wave 4c - the paste that does not fit. The owners decision Q3: paste what fits and keep the rest in the clipboard, or offer the choice. A paste that does not fit the CURRENT PAGE raises an OFFER and is never resolved automatically (D-24); the bound is the page rect, not the viewport, because the camera is clamped to the page and a paste that fits the viewport but hangs off the page is exactly the failure the owner reported. The fit is decided PER LINE (D-25): a line whose element lies entirely inside the page fits, a line that straddles the edge does not, and the count stops at the first line that does not. Whatever is left over is written BACK TO THE CLIPBOARD (D-26), so nothing is thrown away silently. Three answers: discard the rest (place only what fits, write the rest back), place all the text on this page (the page GROWS to contain it, with growPagesToFitContent plus translateContentForPageLayout), and place the text across multiple pages (the text is split into chunks that each fit a page; the first chunk stays on the page the text was pasted on and every further chunk lands on a NEW page appended to the document, so no existing page shifts).
