Wave 5e: the code panel reads like a VS Code editor and is sized like one. The panel now has a tab strip naming the mirrored file and its language, the VS Code dark theme (#1e1e1e surface, #d4d4d4 text, #007acc accent, and the VS Code token colours), and a code region with a floor, so the chrome, the output and the console cannot squeeze the code out of it. The size is no longer a constant: it is a share of the visible canvas, computed by codePanelSize from the viewport and the zoom - on a 1980x2048 canvas it comes out at exactly 990x1024, which is what the owner asked for, and it is clamped to 280-1200 by 200-1200 so it stays usable on a small screen. The brief clamp of 200-900 tall would have capped that canvas at 990x900 and missed the owners numbers, so the bound was widened. Four teeth checks, each confirmed failing with the fix reverted: the file name removed, the theme put back to light, the editors floor removed, and the size forced back to 520x380. Two things are recorded rather than hidden. First, the mirrored text is classified by the only language grammar in the repository, so a call like print(...) is not tagged as a function and is therefore not painted the function colour; a real Python grammar would be a new dependency, which the rules forbid, so this is a follow-up. Second, the panel no longer follows the app theme - it is always the VS Code dark one - and the theme prop had no other user, and PanelOverlay is not exported from the package index, so this is not a public API change. This wave also removed a pre-existing defect in the committed SPEC.md, where the Acceptance - Wave 5c section was duplicated verbatim and the duplicate ids made the kit SPEC lint fail; SPEC.md is in this waves scope, so the second copy is gone. A first cut of this wave imported CodeMirror statically, which broke a test that mocks @codemirror/view and would have pulled CodeMirror into the eagerly loaded bundle; the palette is now an import-free data module and the CodeMirror wiring lives in the lazily imported editor module.
